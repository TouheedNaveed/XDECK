How to Properly Open Specific Chrome / Browser Profiles on XDECK

When setting up browser profiles on Windows, always wrap file paths containing spaces in double quotes "...". In XDECK, use the Start App action kind:

✅ WINDOWS (Start App):
Path: "C:\Program Files\Google\Chrome\Application\chrome.exe"
Args: --profile-directory="Profile 1"
🍎 macOS & 🐧 Linux:
Mac (Run Command): open -na "Google Chrome" --args --profile-directory="Profile 1"
Linux (Start App): google-chrome | Args: --profile-directory="Profile 1"

How to find your Profile directory name: Open Chrome &rarr; Navigate to chrome://version &rarr; Look at Profile Path (e.g., Default, Profile 1, Profile 2).
